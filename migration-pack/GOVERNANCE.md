# NOIZY Governance Framework

## Mission
Protect creators, dreamers, and visionaries through independent infrastructure.

## The 7 Projects

1. **dreamchamber-audio-mcp** - Audio streaming MCP
2. **mcp-gemma3** - Gemma 3 inference wrapper
3. **mcp-framework** - Core MCP protocol
4. **dreamchamber** - Multi-agent orchestration
5. **noizybeast** - Audio/media processing agent
6. **swift-library** - Native Swift utilities
7. **noizyempire-claude** - Claude prompt toolkit

## Repository Structure

All repos under `github.com/noizy-ai/` with unified governance.

## Branch Rules

- Require 1 code owner review on main
- All CI checks must pass
- No force-push

## Commit Standard

Conventional commits: `type(scope): description`
- feat, fix, docs, test, refactor, perf, build, ci, chore

## Security

- No secrets in code
- Environment variables required
- Archive backups on /Volumes/FISH for rollback
