# 🧠 NoizyCockpit

A modular Python orchestration system for managing digital platforms, branding, and automation.

## Modules
- `accounts.py`: Generates account alignment CSV
- `dashboard.py`: Displays and filters account grid
- `voice_trigger.py`: Voice-activated cockpit commands
- `branding.py`: Tracks visual identity across platforms

## Setup
```bash
pip install pandas tabulate speechrecognition pyaudio streamlit
```
