# /morning — Morning Briefing

Gabriel delivers the daily briefing when Rob starts a session.

## Steps

1. GABRIEL: Greet Rob (military-calm, no cheerleading)
   ```
   GABRIEL online. [Date]. [N] days to April 17.
   ```
2. LUCY: Yesterday's summary
   - What was built/shipped yesterday
   - Tasks completed
   - Tasks still open
3. DREAM: Strategic position
   - Current critical path status
   - Top blocker
   - What needs to happen today to stay on track
4. ENGR_KEITH: System health
   - Heaven: up/down
   - DreamChamber: running/stopped
   - Any errors in logs overnight
5. CB01: Ops status
   - Any deploys needed
   - Domain/DNS status
   - Certificate expiry warnings
6. AUDIO: Voice pipeline status
   - Audio Hijack configured
   - Whisper ready
   - Any transcripts from yesterday
7. SHIRL: Wellbeing check
   - How late did Rob work last night?
   - Suggest pace for today
8. GABRIEL: Today's recommendation
   - Top 3 things to build today
   - What to defer
   - "What are we building, Rob?"
